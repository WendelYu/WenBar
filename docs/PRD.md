# WenBar — 产品需求文档（PRD）

## 1. 产品概述

**WenBar** 是一款面向 macOS 14.0+（全面兼容 macOS 26）的原生菜单栏效率工具，采用 Swift 6 + SwiftUI + AppKit 构建，旨在解决 macOS 日常高频痛点：
1. 原生菜单栏时钟自定义能力弱、日历缺少农历与法定节假日/调休展示。
2. 外接硬盘 / U盘在 macOS 读写后被写入 `.DS_Store`、`._*`、`.Spotlight-V100` 等隐藏垃圾文件，放到 Windows 上影响整洁。
3. 缺少贴合 Finder 右键习惯、兼容 Windows 中文编码且能顺手清理 `.DS_Store` 的压缩/解压工具。

---

## 2. 目标用户与运行规格

- **系统要求**：macOS 14.0 (Sonoma) 及以上，针对 macOS 26 适配自适应毛玻璃/材质视觉与系统规范。
- **产品形态**：非沙盒常驻菜单栏应用（`WenBar.app`）+ 沙盒 Finder 同步扩展（`WenBarFinderSync.appex`）。
- **语言支持**：简体中文（主）与 English，支持跟随系统或手动切换。
- **权限边界**：不使用需要隐私敏感辅助功能（Accessibility）的方案；通过 Carbon HotKey 实现全局快捷键，通过 EventKit 读写日程/提醒，通过 DiskArbitration 推出磁盘。

---

## 3. 核心功能需求

### 3.1 模块一：自定义菜单栏时钟与智能日历

1. **自定义菜单栏时间格式**
   - 内置常用格式预设，并支持自定义格式字符串与 `{lunar}`（农历）、`{jieqi}`（节气）、`{week}`（周数）、`{weekday_cn}`（中文星期）宏。
   - 使用等宽数字排版防抖动；仅当格式包含秒数或存在运行中的倒计时/番茄钟时按 1 秒刷新，其余时间按分钟边界触发。
   - 存在倒计时/番茄钟或压缩/解压任务时，在菜单栏展示紧凑进度/剩余时间徽标。
2. **智能日历弹窗**
   - 展示公历、星期、周数、中国农历（含闰月与初一月份名）、二十四节气、传统节日与国务院法定节假日/调休标记（`休` / `班`）。
   - 顶部/底部展示「距离下一个法定假期还有 X 天」。
   - 节假日数据源采用「内置 2025–2027 离线 JSON 兜底 + 后台同步在线数据源（GitHub / jsDelivr 镜像）+ 本地缓存 + 手动刷新」。
3. **系统日历与提醒事项（EventKit）**
   - 点击日期查看当日 Apple 日历日程与提醒事项，支持直接勾选完成待办。
   - 支持在弹窗内快捷新建日程（标题、全天开关、起止时间、目标日历、提前提醒）。
4. **时钟与日期小工具**
   - **倒计时 / 番茄钟**：预设时长（25 分钟专注 / 5 分钟休息 / 自定义），到期发送系统通知。
   - **世界时钟**：添加多个城市/时区，显示当前时间、时差与跨天标识。
   - **日期差计算**：计算两日期之间的自然日天数与工作日天数（结合法定节假日与调休工作日修正）。

### 3.2 模块二：外接硬盘 / U盘管理与防污染

1. **双入口展示模式**
   - 默认在插入外接卷时自动显示独立菜单栏磁盘图标（拔出即隐），同时支持在主弹窗内以卡片形式展示与操作；两者均可在设置中独立开关。
2. **清理并安全推出**
   - 展示卷名、文件系统（exFAT / FAT32 / APFS / NTFS 等）、已用与总容量进度条。
   - 支持单卷「清理并安全推出」「仅推出」及「全部清理并推出」。
   - 默认清理项（可在设置中逐项开关）：`.DS_Store`、`._*`（AppleDouble）、`.Spotlight-V100`、`.Trashes`、`.fseventsd`、`.TemporaryItems`。
3. **安全保护与源头防污染**
   - 自动跳过系统根卷、只读卷、内部固定盘以及 Time Machine 备份盘，清理过程严格不跟随符号链接。
   - 提供系统级 `DSDontWriteUSBStores` / `DSDontWriteNetworkStores` 开关（含重启 Finder 快捷按钮），以及单盘级 `.metadata_never_index` 写入/移除开关。
4. **占用排查与强制推出**
   - 推出失败时自动通过 `lsof` 检测占用进程名与 PID，提供「重试」与带二次确认的「强制推出」。

### 3.3 模块三：Finder 右键菜单压缩 / 解压与 `.DS_Store` 清理

1. **Finder 上下文菜单**
   - 在选中文件/文件夹或目录空白处右键，通过 `WenBar` 子菜单提供：
     - `压缩为 ZIP`
     - `加密 / 自定义压缩…`（支持 `ZIP / 7Z / TAR.GZ`、压缩级别、AES-256 密码、清理源目录开关）
     - `解压到当前目录`（智能解压）
     - `解压到同名文件夹`
     - `清理此目录 .DS_Store`
2. **全格式与 Windows 中文乱码修复**
   - 压缩支持 `ZIP`、`7Z`、`TAR.GZ`；解压支持 `ZIP`、`7Z`、`RAR`、`TAR.*`。
   - 解压 ZIP 前自动解析 Central Directory 编码标志；检测到非 UTF-8 编码（如 Windows 生成的 GBK/GB18030、Big5、Shift-JIS）时自动转换目录头为 UTF-8，避免中文文件名乱码。
3. **`.DS_Store` 双重清理与智能防散落**
   - 压缩包内默认自动排除 `.DS_Store`、`._*`、`__MACOSX`。
   - 提供开关（默认开启）：压缩成功后自动递归清理源目录中的 `.DS_Store`。
   - 智能解压：归档内若只有一个顶层文件夹则直接解出，若包含多个零散文件/目录则自动新建同名文件夹，重名自动编号避让。
   - 可选开关（默认关闭）：解压成功后将原压缩包移至废纸篓。
   - 大文件任务在后台异步执行，在菜单栏显示进度条和取消按钮，完成后发送系统通知；遇加密包自动弹窗询问密码。

### 3.4 模块四：引导、快捷键、设置与未来发布

- **首次启动引导页**：实时检测 Finder 扩展启用状态、日历/提醒事项权限、系统通知权限，并提供一键打开对应系统设置。
- **全局快捷键**：默认 `⌥ + Space` 快速唤起/关闭主弹窗，支持自定义录制。
- **设置中心**：分四页（通用 / 时钟与日历 / 外接磁盘 / 压缩与解压），所有业务模块支持单独开关。
- **发布预留**：支持本地 ad-hoc 免费签名；预留 Developer ID 签名、Apple `notarytool` 公证、DMG 打包脚本以及 Sparkle 2.x 自动更新接口与配置占位。
